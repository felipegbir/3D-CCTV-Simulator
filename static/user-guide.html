1. Getting started

  1. Open the simulator and create or load a project from File.
  2. Import an optimized GLB/glTF model or reference image.
  3. Add cameras, select a camera model, and position it in the Planning Workspace.
  4. Open a Camera View, enable PTZ, create presets, select depth surfaces, and define ROIs.
  5. Save the project as an .nmd file and generate a report when the design is ready.
The dark theme is the default. Project geometry uses metres internally. Imported HVDC/mm models use the configured -90° X rotation and millimetre conversion preset.

2. Workspace

Planning Workspace

The centre area is the editable 3D scene. The Scene Tree lists cameras, models, objects, and zones. The Inspector edits the selected item. Both side rails can collapse without changing saved camera optics.

Navigation and View menu

  • Orbit, pan, and zoom with the normal mouse controls.
  • Reset View restores the standard planning camera and working-grid view; Fit Selected frames the selected item.
  • Zoom In and Zoom Out move the planning camera toward or away from its current target.
  • Open Video Wall uses the current browser; Pop Out Video Wall opens the linked wall in a separate window.
  • Grid and axes visibility are controlled only in Preferences.
  • Use the navigation cube for Front, Back, Left, Right, Top, and Bottom views. The lower scale indicator updates as the planning camera zoom changes.

Edit and Object menus

Edit contains Copy, Cut, Paste, Delete, and Clone. Object contains Add Camera, Add Box Object, Rename Selected, Show in Inspector, and Lock / Unlock Transform. Locking prevents move/rotate edits until the item is unlocked.

4. Models and reference images

  • Prefer optimized GLB/glTF for predictable browser performance.
  • Direct FBX loading is guarded and may use a fallback for large files.
  • After import, verify scale, rotation, position, and units.
  • Use scale calibration when a known real-world distance is available.
Lay Face Flat remains experimental and should not be treated as a verified production workflow.

5. Cameras and Camera Views

  1. Add or select a camera in the Scene Tree.
  2. Choose make/model/lens in the Inspector.
  3. Move and rotate the camera root in the scene.
  4. Open Show Camera View and maximize it to expose Palette, PTZ, Capture, and Presets.
  5. Choose the appropriate visible, thermal, or UV palette.

Camera View outer frames retain the standard 4:3 application-window ratio. The sensor image is fitted inside without changing its optical framing. The attached Presets dock does not consume sensor-image space.

Horizontal FOV is supplied by the camera/lens record. Vertical FOV is derived from HFOV and the camera sensor resolution, then used by the Three.js render camera and vertical pixel-density calculations.

Changing a configured camera model can invalidate optical limits and density results. Use Clone and Apply New Model to compare alternatives without altering the configured camera.

6. PTZ presets

  1. Maximize a Camera View and enable PTZ.
  2. Drag to pan/tilt and use the wheel or controls to zoom.
  3. Open Presets. The manager attaches to the Camera View.
  4. Enter a name or allow automatic names such as Preset 001.
  5. Select Add Current to capture position, rotation, PTZ, optics, palette, and depth state.
  6. Use Recall to animate to the saved view. Movement speed is controlled by the slider.

Manual movement clears the active preset state and hides its ROIs. Recalling the preset restores the saved view and displays its ROIs only after motion finishes.

7. Depth surfaces and ROIs

Select depth

  1. Recall or create the parent preset.
  2. Choose Select Depth Surface.
  3. Click the visible model surface inside the Camera View.
  4. Confirm the depth and live pixel-density values.

Create and edit ROIs

  1. Select Add ROI and draw a polygon on the sensor image.
  2. Use 3–15 nodes. Drag nodes to reshape it.
  3. Click an edge to insert a node; right-click a node to remove it.
  4. Use Edit ROI, Delete ROI, and Show/Hide as required.

The analysis reports ROI pixel width and height, physical bounds, area, depth, and thermography classification. Typical guidance is minimum 3×3 pixels and preferred 9×9 or greater.

8. Calibration and measurement

  • Calibrate Scale: select two points and enter the known distance.
  • Measure Distance: select two surface points. Completed measurements retain an ID and aligned label.
  • Precision: hold Shift for the loupe; set magnification from 2× to 20×.
  • Edge assistance highlights nearby candidate edges for accurate placement.
  • Use Cancel Active Tool or Clear Measurements when finished.

9. Video Wall

  1. Open Video Wall from View.
  2. Select a tile, then choose Planning Scene or a camera from Source.
  3. Choose the required layout and refresh sources after camera changes.
  4. Use Capture, PTZ, and Presets on supported camera tiles.
  5. In 1×1, Presets uses the resizable right-side dock. In 1×2, the manager uses the supported tile layout.
  6. Use Pop Out for a second-monitor wall linked to the current session.

10. Reports

Use the Report menu to configure identity, title, description, page format, included content, and image quality. A report can include:

  • Project title and company/client details
  • Two scene-context views
  • Camera BOM and coordinates
  • Camera-to-target context images
  • PTZ preset images
  • ROI overlays, names, and pixel-density metadata

Overview, opposite-side, and camera-context viewpoints are kept above the grid and scene floor. The opposite view rotates horizontally around the scene target without mirroring the reporting camera below the model.

Choose Generate Report, then use the browser print command to save a letter-formatted PDF.

11. Preferences

  • Theme, grid, axes, navigation cube, and scale-indicator visibility
  • Reverse pan, reverse tilt, and invert zoom
  • Renderer quality and cone opacity
  • Metric decimal precision from 0–10, default 3
  • Model-import preset and large-FBX fallback

Preferences are stored locally and included in project persistence where applicable.

12. Shortcuts and troubleshooting

ActionControl
Undo / redoCtrl+Z / Ctrl+Y
Cancel active ROI/measurement modeEsc
Measurement loupeHold Shift
Hard refresh after an updateCtrl+F5

If a camera view appears empty

Confirm the camera points toward scene geometry, recall a known preset, reset PTZ if needed, and verify that the referenced model is loaded.

If an external asset is missing

Restore the asset at its recorded path or reload it, then confirm the saved transform.

Before final delivery

Save and reopen the .nmd project; recall every preset; verify every ROI; check Video Wall sources; and generate a report preview.
