# N.O.M.A.D. 8e.7.2 — Stabilized PTZ/ROI workspace and user guide

## Release status

8e.7.2 closes the accepted 8e.7.1 correction programme and promotes the stabilized Planning Workspace, Camera View, PTZ preset, ROI, Video Wall, measurement, persistence, and report foundation to the next working baseline.

## Included baseline

- Consistent 4:3 Camera View application frames with sensor-aspect rendering fitted independently.
- Attached PTZ Presets manager with PTZ operation, animated recall, depth-surface selection, multiple polygon ROIs, live pixel-density analysis, and persistent metadata.
- Integrated and pop-out Video Wall with assignable sources, supported PTZ and Presets workflows, and stable renderer lifecycle.
- Project schema 7 and `.nmd` persistence for cameras, presets, ROIs, measurements, preferences, workspace state, referenced assets, and report settings.
- Calibration/measurement tools, navigation cube, scale indicator, configurable precision loupe, and identified measurements.
- Report configuration, BOM, scene/preset imagery, ROI overlays, and analysis metadata.

## 8e.7.2 additions

- The attached Camera View Presets dock uses border-box sizing so its outside height exactly matches the owning Camera View.
- Help now opens a standalone, responsive, dark-themed HTML user guide covering the complete current workflow.
- Application title, visible version labels, About information, generated report identity, and Video Wall title use 8e.7.2.
