# N.O.M.A.D. CCTV Simulator 8e.7.5

## Project model-source restoration

- Project schema 8 records every model's file name, best available source path, source route, format, storage type, and server-library fallback route.
- Normal Save Project remains the `.nmd` workflow. Export Project JSON produces the same readable project structure with a `.json` extension for inspection/interoperability.
- Load Project compares the saved camera/model set with the active scene and lists any current cameras or models that will be removed. Cancel leaves the current scene unchanged.
- After confirmation, missing GLB/glTF assets are restored from their saved `/models/` route or retried from the server model library by file name before current scene-only cameras/models are removed.
- Late starter-model and local-import callbacks are generation-guarded so asynchronous loads cannot contaminate a restored project.
- Direct automatic FBX restoration remains guarded. Re-import FBX or, preferably, convert it to optimized GLB.

Browser security can hide an absolute workstation path selected through a file picker. When that happens, the project records the available file name/path reference; automatic loading requires a matching asset in the server model library or manual re-import.

## Menu consolidation

- Removed duplicate Save As and Open Project File commands; Load Project and Save Project are the canonical workflows.
- Renamed Export JSON to Export Project JSON and documented its distinction from `.nmd` Save Project.
- Removed the duplicate Edit > Add Box command; Object > Add Box Object is canonical.
- Added View > Zoom In and retained Zoom Out.
- Merged Fit Grid into Reset View and removed duplicate View grid/axes toggles; Preferences is the sole grid/axes control.
- Clarified Object commands as Rename Selected, Show in Inspector, and Lock / Unlock Transform.
