# VISTA 3D Inspection Simulator 8e.7.5-vista.1

## Purpose

This VISTA-specific maintenance release preserves the accepted N.O.M.A.D. 8e.7.5 functionality while correcting report overview and camera-context viewpoints in the VISTA-hosted deployment.

## Implemented

- Report overview and context cameras are now positioned above the complete scene bounds.
- Report cameras no longer rely only on the grid, floor, or target elevation.
- Clearance is calculated from the full scene height.
- Primary overview, opposite-side overview, and camera-context images avoid below-model or underside framing.
- PTZ preset images remain captured from the actual camera perspective and are unchanged.

## Validation

- Default transformer model loads successfully.
- Camera database API responds successfully.
- Docker container reports healthy.
- Traefik routing through `simulator.vista.lan` works.
- Uptime Kuma monitor is active.
- Owner report-generation QA confirmed useful above-model images.
