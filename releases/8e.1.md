# N.O.M.A.D. 8e.1 - PTZ Save/Load Restoration

Status: implementation complete; pending live deployment validation  
Scope authority: approved roadmap item 8e.1 only

## Change

- Project loading now restores `pan`, `tilt`, `roll`, and `zoom` from the current nested camera data structure.
- Legacy project files with top-level PTZ fields remain supported.
- `applyCameraPtzRig(item)` now runs after camera data restoration and before projection refresh, ensuring the saved pivot orientation becomes visible immediately.
- Added `scripts/test_ptz_persistence.py` as a regression guard for persistence fields, save coverage, and call ordering.

## Unchanged

- PTZ hierarchy remains camera root > pan pivot > tilt pivot > roll pivot.
- Projection cone and render camera remain under the roll pivot.
- Project schema is unchanged; schema versioning belongs to 8e.2.
- No theme, preferences, presets, measurement, occlusion, persistence, reporting, or service-management work is included.

## Required validation

- Static frontend contract audit.
- JavaScript module syntax check.
- PTZ persistence regression guard.
- Save/load round trip with non-zero pan, tilt, roll, and zoom.
- Projection cone and camera viewport remain aligned after load.
