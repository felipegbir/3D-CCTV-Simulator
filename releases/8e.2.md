# N.O.M.A.D. 8e.2 - Project Schema and Asset Warnings

Status: complete; owner accepted 2026-07-24  
Scope authority: approved roadmap item 8e.2 only

## Schema contract

- New project files use numeric `schemaVersion: 2`.
- Files record `appVersion: "8e.2"` and an ISO-8601 `savedAt` timestamp.
- Existing unversioned 8e and 8e.1 files load as schema 1 in compatibility mode.
- Invalid schema values are rejected.
- Future schema versions above 2 are rejected with a clear instruction to use a newer simulator.

## Asset manifest and warnings

- New saves include an `assetManifest` with model and reference-image records.
- Server-backed models are marked as restorable.
- Browser-local GLB/FBX models are marked `browser-session` and not restorable.
- Reference images are marked `browser-session` and not restorable.
- Structured warning codes:
  - `LOCAL_MODEL_NOT_EMBEDDED`
  - `REFERENCE_IMAGE_NOT_EMBEDDED`
- Users must confirm before saving JSON that references non-embedded assets.
- The same structured warnings are shown when the project is loaded.
- Camera records and transforms still load; users are instructed to re-import missing local assets.

## Unchanged

- This release does not upload, embed, or persist model/image binaries.
- NAS-backed asset persistence remains scheduled for 8e.8.
- PTZ behavior remains the accepted 8e.1 implementation.
- No theme, preference, preset, measurement, occlusion, reporting, or service-management work is included.

## Automated validation

- Static schema and warning regression guard.
- Runtime manifest classification for server-backed model, local FBX, and reference image.
- Runtime compatibility checks for legacy, current, invalid, and future schema versions.
- Baseline 8e and PTZ 8e.1 regression suites remain required.
