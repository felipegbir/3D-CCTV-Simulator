# N.O.M.A.D. 8e.7.1 - PTZ Presets

Status: implementation complete; live deployment and owner acceptance pending.

## Scope

### A - Schema and preset state

- Application version 8e.7.1 and project schema 4.
- Per-camera `ptzPresets` collections with stable IDs, names, notes, timestamps, PTZ, optical state, projection depth, palette, camera transform, depth target, camera/lens identity, ROI inputs, derived footprint, horizontal/vertical pixel density, estimated ROI pixel coverage, and thermography classification.
- Legacy schema 1-3 files load in compatibility mode with empty preset collections; schema-4 files restore complete preset state.

### B - Preset management

- Shared PTZ Presets manager available from the camera inspector, floating Camera View header beside PTZ, integrated Video Wall, and linked pop-out Video Wall.
- Existing preset list plus Recall, Add Current, Save Details, Update Current, Delete, and Select Depth Surface actions.
- Save Details edits name/notes/ROI without changing the stored PTZ target. Update Current deliberately recaptures current PTZ/optical/depth/palette state.
- Delete requires confirmation.
- Select Depth Surface raycasts only valid model/reference surfaces and records the target identity, world hit point, distance, and timestamp.

### C - Animated recall

- Recall uses cubic ease-in/ease-out animation and shortest-path pan/roll interpolation.
- Adjustable 1-60 degrees/second movement speed, default 10 degrees/second, stored in browser/project preferences.
- Pan, tilt, roll, focal length/zoom, HFOV, projection depth, cone, and camera render update during movement.
- Final state snaps exactly to the preset and applies its visualization palette across open floating and wall views.
- Manual pan/tilt/roll/zoom immediately cancels active preset recall.

### D - Persistence and validation

- Schema-4 save/load includes preset arrays and speed preference.
- Static, JavaScript syntax, legacy PTZ, preferences, schema, theme, renderer parity, measurement, Video Wall, preset source, preset normalization, shortest-angle, cancellation, and animation runtime checks pass.

## Known constraints

- Preset recall changes the PTZ/optical/depth/palette state; it intentionally does not relocate the installed camera root even though the captured installation transform is retained for audit/reporting.
- ROI pixel coverage remains a planning estimate and does not guarantee thermographic measurement performance.
- Visibility/occlusion analysis remains scheduled for 8e.7.2.
- Linked pop-out Video Wall preset actions use the originating session's shared preset manager.
