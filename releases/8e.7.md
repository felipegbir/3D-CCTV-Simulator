# N.O.M.A.D. 8e.7 - Planning Workspace, Video Wall, and Measurement

## Scope

Release 8e.7 preserves the accepted floating camera-viewport workflow and introduces an independent Video Wall workspace. It also delivers the original scale-calibration/measurement scope, the HVDC/mm import preset, the requested Help/About split, and schema-3 persistence.

## Implemented

- Renamed the normal operating context in UI language to **Planning Workspace**.
- Removed the redundant Operations > View theme command; theme remains in Preferences.
- Split Help and About into separate collapsible groups. Help reserves the future manual link; About retains version, legal, contact, package, and publication information.
- Preserved floating camera windows, focus-to-front, minimize/maximize, drag, close/dispose, and the 16-camera limit.
- Replaced floating-window arrangement with an independent Video Wall overlay.
- Added Planning Scene as a Video Wall source plus up to 16 camera sources.
- Added Auto and 1x1 through 5x5 layouts and drag/drop tile reordering.
- Added a linked pop-out Video Wall window for a second monitor. The originating Planning Workspace remains authoritative; closing it ends the live link.
- Added an HVDC/mm import preset, enabled by default, applying -90 degrees on X and scale 0.01 to GLB/glTF and FBX imports. As Exported remains selectable; the prior large-FBX fallback remains available there.
- Added two-point surface distance measurement in metres.
- Added two-point scale calibration for the selected model, including a real-distance prompt, uniform scale application, calibration metadata, and persistent visual line.
- Advanced the project schema to version 3.
- Schema 3 persists preferences, Video Wall layout/order, model metadata/calibration, measurements, and external reference-image transforms. External binary model/image content remains outside the project JSON.

## Known constraints

- Video Wall pop-out is linked to the in-memory originating browser window, not a separately loaded independent project session.
- Browser pop-up blocking must be disabled for the simulator site to open the second-monitor window.
- Measurement clicks target loaded model/reference surfaces; helpers and empty space are ignored.
- Calibration applies a uniform scale and does not enter the current transform-only undo stack.
- Browser-local external assets still require the referenced source files to be re-imported in a new browser session; schema 3 retains references, transforms, and metadata but does not embed binaries.
- Lay Face Flat remains incomplete.
